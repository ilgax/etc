# etc

Miscellaneous small projects.

- `tab-hotspot-helper/`: command-line helper that starts the hidden Wi-Fi hotspot on a Wi-Fi-only Galaxy Tab via Shizuku.
- `wear-portal-login/`: Wear OS captive-portal login browser.

## Moved

The Utils Android app (speaker kill switch, hotspot, watch remote, equation solver) and the Tab Remote watch app now live in their own repository, with history:
**[ilgax/AndroidUtils](https://github.com/ilgax/AndroidUtils)**. The former `android-utils/` and `watch-remote/` folders were removed from here.
